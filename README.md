# TVC Director · TVC 广告创意导演技能说明

把产品 brief 变成可直接投产的 **Nano Banana Pro 关键帧提示词** 和 **Seedance / 即梦视频提示词**——从创意提案、视觉定调、前期筹备到分镜与拍摄的完整导演工作流。

## 适用场景

- TVC 广告、产品宣传片、品牌片、产品 Hero 视频
- 「帮我做一条产品广告」「我需要一个 TVC 分镜」「帮我做一个产品 Hero Shot」均可触发
- 纯概念阶段 → 全套提示词交付；已有分镜脚本 → 直接转化；已有生成结果 → 迭代修正

## 三大核心能力

| 能力 | 说明 | 适用产品 |
|------|------|---------|
| 产品电影化拆解 | 纯影棚多段式产品微电影：零件悬浮拆解、材质微距、精确到秒的运镜编排 | 数码、硬件、精密产品 |
| 品牌世界穿梭 | 产品特写与使用场景交叉剪辑，Match Cut 衔接（运动相机×跳伞、越野车×盘山弯道） | 有强使用场景的产品 |
| 生活方式短片 | 产品始终穿戴/持握在人物身上，靠运镜在场景内自然突出 | 穿戴、生活方式品类 |

## 运行流程

```
① 创意简报     产品 / 产品参考图 / 时长 必问，其余给默认值
     ↓
② 创意提案     2-3 个创意方向 → 选定 → 完整 TVC 方案文档
     ↓
③ 视觉定调     画风 A-E 确认（🚧 未确认不出任何提示词）
     ↓
④ 前期筹备     ★ 分镜驱动方式卡片：静帧关键帧（默认）/ 白模分镜视频 / 混合
              → 资产清单推导 → 资产图提示词（产品多视图默认）
              → 一致性锚点（产品/出镜者标准描述）
              （🚧 产品多视图未锁定不生成分镜）
     ↓
⑤ 分镜与拍摄
   分镜规划表（🚧 产品出镜率验证：全片 ≥70%，单 Grid ≤2 格无产品）
   后期剪辑询问 → 按视觉语境拆素材 / 不拆
   多宫格/单帧提示词（Nano Banana Pro）
   ★ 模型选择卡片：Seedance 2.5（官方架构）/ 其他（Multi-Phase 通用格式）
     —— Phase 4 选了白模驱动时自动锁定 Seedance 2.5
   End Frame 提示词
     ↓
⑥ 审片         生成结果反馈 → 单变量迭代修正
     ↓
⑦ 交付         项目文件夹归档
```

快速入口（非全流程）：

- **快速提示词**：直接进 ③ 视觉定调 → ④ → 出提示词
- **分镜转化**：自带脚本进 ③ → ④ → ⑤
- **迭代修正**：直接进 ⑥ 审片

## 提示词工具分工

| 产物 | 工具 | 格式 |
|------|------|------|
| 资产图 / 多宫格 / 单帧 / End Frame | Nano Banana Pro | 六层结构中文提示词 |
| 视频提示词（默认） | 即梦等 | Multi-Phase 通用格式 |
| 视频提示词（选 Seedance 2.5） | Seedance 2.5 | 官方架构（见下） |

## Seedance 2.5 官方架构要点

选择 Seedance 2.5 后，视频提示词按 `references/seedance-2.5.md` 输出，核心语法：

- **@素材职责**：每份素材逐份声明「采用什么、不采用什么」；多视角图共同定义同一产品
- **首尾帧 / 多关键帧**：`@图片1作为首帧…`、`以@图片1至@图片N的顺序作为关键帧`，逐张声明
- **阶段写法**：【生成目标】→【阶段N：开始时/主要事件/结束时可见状态】→【保持一致】
- **声音符号**：音乐 `( )`、音效 `<>`、台词 `{ }`、字幕`【 】`；TVC 固定句「无背景音乐，只保留环境声和动作音效。不要字幕。」
- **白模参考**：粗粒度（继承运动骨架，几何体逐体映射）/ 细粒度（完整建模重渲染材质）；支持 TapNow 导演台等 previs 工具产出的白模分镜视频
- **运镜表达**：热门运镜术语直接用，小众术语必须翻译成可见画面变化
- **提交前检查**：每段 2.5 提示词交付前，按第 14 节检查清单逐项自检（素材职责、逐体映射、阶段单一变化、画幅一致性等），先修正再交付

## 技能文件结构

```
tvc-director/
├── SKILL.md                      # 主流程：Phase 0-7 + 核心约束（12 条铁律）
└── references/
    ├── treatment.md              # 创意导演：叙事模型 A-H、出镜策略、品类适配
    ├── pre-production.md         # 前期筹备：资产规划与一致性维护
    ├── shot-language.md          # 镜头语言：提示词句法、画风锚定词库 A-E
    ├── storyboard.md             # 分镜与视频：多宫格、Multi-Phase、产品拆解系统
    ├── seedance-2.5.md           # 视频模型：Seedance 2.5 官方架构（14 节）
    └── delivery.md               # 交付与迭代：输出格式、调试策略
```

## 项目交付物结构（Phase 7 归档）

```
<project-name>/
├── concept.md                # TVC 创意方案文档
├── storyboard.md             # 分镜脚本（如有）
├── assets/prompts/           # 资产图提示词（产品多视图、场景图…）
├── keyframes/prompts/        # 关键帧提示词（多宫格、End Frame…）
└── video-scripts/            # 视频提示词（格式按模型选择）
```

## 能力边界

专注视觉创作（关键帧提示词 + 视频提示词）。**不含**：广告文案/Slogan、旁白/VO、BGM/音乐、后期剪辑、媒体投放。Logo 与 Slogan 一律后期叠加（End Frame 预留空间）。

## 三条最常用的铁律

1. 画风未确认，不出任何提示词
2. 产品多视图未锁定，不生成分镜关键帧
3. 全片产品可见格 ≥ 70%——TVC 是产品广告，不是风景片
